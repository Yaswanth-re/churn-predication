# 📊 Customer Churn Analysis & Prediction (Power BI + SQL + Machine Learning)

This repository contains a complete churn analytics project combining Power BI dashboards, SQL-based data processing, and a Random Forest classifier to predict customer churn.

The aim of this project is to analyze why customers leave, their behavior patterns, and predict future churners so businesses can take preventive actions.

---

## 📌 Project Objectives

- Understand customer churn behaviour
- Identify key churn drivers
- Predict potential churners
- Build visually interactive dashboards
- Support business decisions with insights

- Probability of churn

---

## 🚀 Key Insights

- Month-to-month contracts show highest churn
- Fiber internet users churn more
- Short-tenure customers are higher risk
- Credit card auto-payment reduces churn
